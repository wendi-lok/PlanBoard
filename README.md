# PlanBoard · 本地项目计划管理

一个**单文件、零依赖**的本地项目管理工具：甘特图 / 看板 / 列表 / 仪表盘四个视图，
把项目、任务、依赖、状态、进度、附件、涂色全都装进一个 `index.html` 里，双击就能用。

## 怎么用

解压后**双击 `index.html`** 即可，用浏览器打开就能用。

不需要装任何软件、不需要联网、不需要启动服务。

> 请保留 `index.html` 的完整文件名与后缀，直接双击打开（不要用编辑器打开）。

---

## 数据存在哪

数据默认保存在**浏览器本地**（localStorage），换电脑或换浏览器不会同步。

不过这一版加了**项目文件**：一个项目可以单独存成一个 `.planboard` 文件带在身上
（详见[项目文件与标签页](#项目文件与标签页)），拷到别的机器上拖进页面就能打开。

另外顶栏「数据」菜单里还有整库的**导出 / 导入 JSON 备份**，建议定期做一次。

## 项目文件与标签页

顶部的项目栏是一条**浏览器式标签页**：一个项目一个标签，标签上有：

| 元素 | 含义 |
| --- | --- |
| 项目色圆点 + 项目名 | 项目身份 |
| 小黄点 / 任务条数 | 有未存进文件的改动时显示小黄点，干净时显示任务条数 |
| `▾` | 展开[项目任务总览](#项目任务总览标签页上的-) |
| `✕` | 关闭这个标签页（会先问你要不要保存） |

标签栏最右还有「**＋ 新建项目**」和「**管理项目**」（改名 / 改色 / 归档 / 删除）。

- 小技巧：**中键点标签** = 直接关闭；**双击标签上的名字** = 就地改名。
- 注意：「全部项目」不是单个项目，所以它没有 `▾` / `✕`，也不能存成文件。

顶部菜单栏是 Word 那种风格：**文件 / 编辑 / 视图 / 数据 / 帮助**，点一下展开。
「文件」菜单里跟项目文件有关的是：

| 菜单项 | 说明 |
| --- | --- |
| 新建项目标签页 | 开一个新的空项目标签 |
| 打开项目文件… | 选一个 `.planboard`（或整库 `.json`）读进来 |
| 保存 | 把当前标签页的项目写进文件（`Ctrl+S`）。已关联过文件就直接写回原文件；没关联过会弹「保存到哪」，可以自己选位置 |
| 另存为… | 换名字 / 换位置再存一份（`Ctrl+Shift+S`） |
| 查看项目任务总览 | 展开当前项目的全部任务树 |
| 恢复最近关闭的标签页 | 关错了可以捡回来 |

直接把 `.planboard` 文件**拖到页面里**也能打开（整库 `.json` 备份同样认）。
如果拖进来的项目 id 和当前开着的某个标签页一样，会问你是「覆盖」还是「开一个副本」。

> **关于「自选保存位置」**
> 能不能挑位置取决于浏览器。新版 Chrome / Edge 支持，保存时会弹出系统的另存为对话框；
> 不支持的浏览器（或直接用 `file://` 打开的老内核）会退回「下载到下载目录」，
> 功能一样，只是位置不能挑。

每个标签页关掉之前如果还有没保存的改动，会问你三选一：
**取消** / **不保存，直接关闭** / **保存到文件再关闭**。

## 项目任务总览（标签页上的 ▾）

点标签上的 `▾`，会在标签下面拉出一块总览面板，一次看清这个项目里有什么：

- **顶上一行**：项目名 + 「N 项 · 完成 M · 百分比 · 总工时」+ 一条总进度条
- **下面是一棵完整的任务树**，每一行包含：
  展开箭头（`▾`/`▸`，点它展开收起这一支）、状态色圆点、任务名、
  `◆`（里程碑）、子任务数量胶囊、完成度百分比、一条小进度条
  —— 已完成的条目会变灰，方便一眼扫出还剩什么
- **底部**「全部展开 / 全部收起」两个按钮
- **单击某一行** = 选中（和其他页面一样，会同步高亮）；**双击** = 打开这个任务的编辑窗口

按 `Esc`、点别处、或者再点一次 `▾` 都能收起。

> 面板里这棵任务树，和仪表盘「各项目进度」里点 `▸` 摊开的是**同一份东西**，
> 只是入口不同：想在全局视角（几个项目并排对比）里看，就用仪表盘那个 `▸`。

## 列宽（像 Excel 那样拖）

**列表视图**

把鼠标移到表头某两列之间的分界线上，光标会变成「左右箭头」，按住拖动就能改这一列的宽度。
**双击分界线** = 这一列自动缩到刚好放得下内容。列宽会记住，下次打开还是这个宽度。

菜单「视图 → 重置列表列宽 / 列表列宽适应内容」可以一键还原或全部自适应。

**甘特图左侧大纲列**

同样是按住表头「任务 / 阶段」右边缘的分界线左右拖。
**双击分界线** = 恢复默认的 310px（菜单「视图 → 大纲列宽恢复 310px」同效）。

拖宽拖窄的时候，时间轴会跟着平移，你原来盯着的那一天不会跑掉。

## 用时（天）：从开始到现在走了多久

三个地方都会显示同一个「用时」：

- 列表视图最后一列（在「进度」右边）
- 悬停时的信息卡（在日期那一行下面）
- 双击打开的编辑窗口（「完成时间 · 用时（天）」那一栏）

**怎么算**

- 用时 = 从「开始日期」到今天的天数；刚好同一天显示「当天」
- 任务一旦变成「已完成」类型，用时立刻锁死在 **开始日期 → 完成那天**，
  之后不管过多少天，这个数字都不再变化（因为终点换成了完成日，不再是「今天」）
- 没填「开始日期」的任务显示「—」
- 在编辑窗口里改「开始日期」，用时当场跟着重算

**一眼分辨**

| 样子 | 含义 |
| --- | --- |
| ⏳ 蓝色 | 还在走（任务没完成，天数随日历增长） |
| 🔒 灰色 | 已固定（任务已完成，天数定格） |

鼠标停在列表那一格上，能看到完整口径，例如：
「用时 8 天（2026-09-23 → 2026-10-01，已完成已固定）」

导出 CSV 时，「用时(天)」这一列用的是同一套算法。

## 附件（每个任务都能挂东西）

双击任意任务打开编辑窗口，右栏就是「附件」。这里只有**两条路**，别找第三条：

| 想挂什么 | 怎么加 | 单击它会发生什么 |
| --- | --- | --- |
| **Markdown 笔记**（`.md`） | 点「**📝 点击添加 Markdown 笔记 / PDF**」选文件，或者把 `.md` 直接拖进虚线框 | **打开只读预览卡片** |
| **PDF**（`.pdf`） | 同一个按钮选 `.pdf`，或者把 `.pdf` 拖进虚线框 | **打开预览卡片**（内嵌阅读器，能翻页 / 缩放） |
| **其它任何格式**（Word / Excel / PPT / 图片 / 压缩包 / 文件夹…） | 只有一条路：点「**📋 粘贴文件路径**」，把绝对路径粘进去 | **把这个路径复制到剪贴板** |
| 网址 | 点「**🔗 外部链接**」，填名字和网址 | 在新标签页打开 |

每条附件右边的 **✕** 把它从任务上摘掉。

> **为什么 MD 和 PDF 能直接上传，别的不能？**
> 因为浏览器**自己就能把它们渲染出来**（Markdown 用自带渲染器，PDF 用 Chrome 内置的 PDF 阅读器），
> 不需要调起任何本机程序。
> 而 Word / Excel / PPT 这类，网页从设计上就没有打开它们的能力（下面细说）——
> 与其存一份只能下载、点了没反应的副本，不如只记一行路径：
> 项目文件保持小巧，而这条路径随时能粘到资源管理器里用。

### 路径型附件：单击 = 复制路径

加一条的步骤：

1. 去资源管理器里把路径拿到手，三种拿法都行：

   | 拿什么 | 怎么弄 |
   | --- | --- |
   | **某个文件 / 文件夹** | 选中它 → <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>C</kbd>（Win11）；或 <kbd>Shift</kbd> + 右键 →「复制文件地址」 |
   | **它所在的文件夹** | 在资源管理器**地址栏**点一下 → <kbd>Ctrl</kbd> + <kbd>C</kbd> |

2. 点「📋 粘贴文件路径」，把路径粘进去，回车或点「添加」。

   带引号也认（`"D:\资料\报表.xlsx"` 会被洗成 `D:\资料\报表.xlsx`），
   网络路径 `\\nas\share\报表.xlsx` 也认。

之后：

- **单击**这条附件 → 路径进剪贴板，提示条里会把完整路径写出来；
  到资源管理器里按 <kbd>Ctrl</kbd> + <kbd>L</kbd> → <kbd>Ctrl</kbd> + <kbd>V</kbd> → 回车，就能直接定位过去
- **双击**附件行 → 改这条路径
- 同一条路径加两次会被拦下来

**附件行只显示文件名**（例如 `需求说明 V2.docx`），后面跟一枚类型徽标
（`DOCX` / `XLSX` / `文件夹` / `链接`…）。
完整路径放在**鼠标悬停**的提示里，不占地方。

### 为什么网页不能直接打开文件？

这是浏览器的硬性安全设计，不是本程序偷懒：

- 早年的 Chrome 提供过 `File.path` 字段，网页确实能读到真实路径；**后来被整个移除了**，
  理由是「网页不该知道用户硬盘上的目录结构」。现在网页拿到的 `File` 对象里只有
  **文件名、大小、类型**，**没有位置**。
- 网页也不能导航到 `file://` 去「打开」什么 —— 顶多让浏览器自己渲染一个目录列表页。
- 唤起本机软件只有一条路：自定义协议（`ms-excel:` 这类）。而这条路在**中文路径**上必然失败：
  浏览器一定会把中文编码成 `%E4%B8%AD%E6%96%87`（URL 规范的强制要求），
  而 Office 的协议处理器**不做解码**，直接拿它当文件名 → 弹「无法找到该路径」。

> 你可能见过某些软件能做到 —— 比如 VS Code 里拖个文件进去它就知道完整路径。
> 那是 **Electron 这类桌面应用**，走的是 Node 的文件接口，
> 和浏览器网页根本不在一个权限层级上，不能比。

所以这一版**干脆不做任何「打开」的尝试**：路径型附件只负责把路径交还给你，
剩下那一步（在资源管理器里打开）交给系统本身。不会再有莫名其妙的报错框。

### Markdown 笔记 / PDF：单击弹出预览卡片

点「📝 点击添加 Markdown 笔记 / PDF」选一个 `.md` 或 `.pdf`（也可以直接把文件拖进虚线框），
之后**单击**这条附件就会弹出一张悬浮在屏幕正中的大卡片：

- 卡片宽度最多 **1240px**、高度占满 **94% 视口**
- 卡片后面的背景做**高斯模糊**，卡片本身保持清晰
- 卡片里按类型分别渲染：

  | 类型 | 卡片里长什么样 |
  | --- | --- |
  | **Markdown** | 标题 / 粗体斜体 / 有序无序列表 / 任务清单 `- [x]` / 行内代码与代码块 / 表格 / 引用 / 分隔线 / 链接 / 图片 |
  | **PDF** | 一个**内嵌的 PDF 阅读器**（就是 Chrome 自己的那套）：左侧缩略图、翻页、页码、缩放、下载、打印全都照旧可用 |

- 纯**只读** —— 卡片里没有任何输入控件
- **Markdown** 卡片支持 **<kbd>Ctrl</kbd> + 滚轮**缩放正文字号（0.7 ~ 2.6 倍；标题会跟着一起缩放，
  顶栏右侧实时显示百分比）。这个倍率会记住，下次打开还是这个大小
- **PDF** 卡片的缩放 / 翻页交给内嵌阅读器自己那排按钮（卡片里的 <kbd>Ctrl</kbd> + 滚轮不接管）
- 右上角还有一个「**↗ 新窗口打开**」，PDF 想放大看时可以直接甩到浏览器独立标签页里
- 关掉它：点**顶栏最右**的 <kbd>✕</kbd>、点卡片外面的模糊区域、或者按 <kbd>Esc</kbd>

> 卡片下方**没有**底栏 —— 所有操作都收在顶栏那一行里。

预览读的是内嵌副本，所以整个 `.planboard` 拷到别的电脑上也照样能看。
PDF 卡片里的 blob 地址在关闭时会自动回收，不会一直占着内存。

### 体积限制

只有 Markdown 笔记和 PDF 会**内嵌**进项目文件（所以 `.planboard` 是自包含的，拷走也能用）。
代价是不能太大：

| 类型 | 单份上限 |
| --- | --- |
| Markdown 笔记 | **1.6 MB** |
| PDF | **2.6 MB** |
| 两个加起来（整库内嵌总量） | **4 MB** |

超了会弹提示，并建议你改用「📋 粘贴文件路径」——只留一行路径就不占体积了。

路径型附件**不占任何体积**（只存一行字），所以视频、设计源文件这类大文件尽管往里挂。

挂了附件的任务，在看板卡片上会显示「📝 笔记 / 📕 PDF / 📎 路径 / 🔗 链接」四色小角标，
鼠标悬停信息卡里也会列出附件名字。

## 全站统一的操作手感

所有页面（仪表盘及其展开的任务列表 / 甘特图 / 看板 / 列表 / 项目总览面板）现在是**同一套**：

| 动作 | 效果 |
| --- | --- |
| **单击** | 高亮选中（按住 <kbd>Ctrl</kbd> / <kbd>⌘</kbd> 多选，<kbd>Shift</kbd> 追加） |
| **双击** | 打开任务编辑窗口 |
| **鼠标悬停** | 冒出一张简洁的信息卡（任务名 / 状态 / 项目 / 优先级 / 日期 / 进度 / 工时 / 备注前几行 / 附件），不会挡住任务条本身 |

信息卡**出现在鼠标指针旁边**（默认右下方），靠边时自动翻到另一侧、压到条时自动让开 ——
悬在长条右半截它就跟着出现在右边，不会跑回条头去。

信息卡可以在「编辑」菜单里关掉（「悬停显示任务信息卡」）。
开着的时候，任务条 / 行 / 卡片自带的浏览器原生小提示会**自动让位**（不会两个框叠在一起）；
关掉之后，原生提示照旧出现。

## 主要功能

### 仪表盘

- 统计卡 / 状态环形图 / 优先级分布 / 各项目进度 / 逾期与临期清单
- **完成时间统计**：已记录完成数、平均完成耗时、相对截止提前或超期、
  近 14 天完成趋势、最近完成记录
- 「各项目进度」里每个项目前面有个 `▸`：点一下就在这个项目下面摊开它的**完整任务列表**
  —— 层级缩进、状态色点、子任务数胶囊、完成度百分比、进度条，已完成的会变灰，
  带 `◆` 的是里程碑；列表里还能一层层继续展开 / 收起
- 展开状态会记住，刷新页面后还开着；点项目名那一行本身仍然是「切换到该项目」

### 甘特图

- 左侧大纲按**项目**分成一组一组：每个项目先占一行（项目色点 + 项目名 + 一条进度微条 +
  完成度百分比 + 任务条数），项目里的任务都排在它下面并缩进一级
- 点这一行（或它左边的 `▽`/`▸`）= 整组展开 / 收起，收起后只留项目那一行；
  **收起状态会记住**，刷新后还是收着的；双击项目名 = 切到只看这个项目
- 右键项目行还有「展开 / 收起这组 / 只看这个项目 / 展开全部 / 全部收起 / 重命名项目 / 管理项目」
- 项目行在时间轴上还会画一条横跨该项目全部任务时间跨度的**浅色汇总条**，
  一眼就能看出这个项目占了哪段时间。表头写着「N 个项目 · M 条任务」
- 日周月三档粒度 + 连续缩放（工具栏 `－`/百分比/`＋`，或 <kbd>Alt</kbd>+滚轮）
- 拖条左右平移、拖两端改工期、拖父阶段级联移动子任务
- 拖条上下移动可以在同级之间换行调整顺序（拖起来的行会浮起，空出来的位置有一根占位条，
  其他行实时让位），**只在同级里换位、不会偷偷改任务的层级**
- 支持依赖箭头、里程碑、今日线，每行行尾圆点可直接切换任务状态
- 每条任务条外面还套了一圈**彩色外框**，这个外框的颜色 = 该任务的**状态颜色**，
  所以不用看文字也能一眼扫出哪些在做、哪些卡住了
- 鼠标悬停或看条上的文字还能同时读到「任务名 · 状态 · 进度」。条形宽度够就把文字写进条内，
  放不下时自动移到条形外侧（右端贴边时改放左侧），文字永远不会被截断
- 条上文字的颜色会**按条身明暗自动挑**（亮条配深字、暗条配白字，不用手动调），
  也能在任务编辑窗口里给某条固定一个颜色，详见[任务条上的文字颜色](#任务条上的文字颜色)
- 工具栏 / 侧边栏里有「隐藏任务条文字」开关，收起来之后只剩色条 + 状态外框，画面立刻清爽；
  外框的粗细还有一个滑条可以调（0 = 干脆不要外框），详见[左侧设置抽屉](#左侧设置抽屉所有开关都收在这里)
- 每个任务条还能**右键单独指定一个颜色**（见[颜色](#颜色想选什么色都行)章节）
- 鼠标靠近某条任务时，它的两端会冒出两个**连线圆点**（颜色同任务条），
  可以把它们拖到别的任务上建立前后依赖，或拖到空白处直接新建任务
- 依赖线加粗并带描边，深浅色主题都看得清；点它就能选中（浮出小操作条），右键可快捷编辑或删除
- 左键在空白处拖拽可**框选**多个任务；按住中键（滚轮键）拖拽可以随手平移整个视图
- 右下角有一个**画笔圆按钮**，点一下就能给时间表背景涂色 / 擦除（详见下文）
- 工具栏上还有一个「新建后弹窗」开关，控制拖圆点新建任务后要不要弹窗
- 任何操作导致重新渲染后，**视图都停在原来的位置**，不会跳回左上角

### 看板

- 列由「任务状态」自动生成，拖拽卡片改状态并排序，列底回车快速新增
- 卡片上直接显示子任务汇总（「▾ N 个子任务 · X h」），点一下就能就地展开，

  拖到某一列的**上下边缘**会自动滚动该列内部；越贴近边缘滚得越快，靠边时会亮起一条渐变提示

- 树形展开折叠，内联改状态 / 优先级 / 起止日期，多种排序（含按状态排序）

甘特图左侧的任务大纲：单击整行高亮（不会弹窗）、双击才打开编辑弹窗、

## 颜色：想选什么色都行

所有能改颜色的地方，都提供了**三种选法**：

1. **一排预设色块** —— 点一下就换（项目色 / 任务条色 / 状态色 / 画笔色都适用）
2. **完整 RGB 取色器** —— 色块最右边那个彩虹小圆点，点开就是系统级的取色器，
   色相、明度、透明度随便调，什么颜色都能选
3. **十六进制输入框** —— 面板下方可以直接敲 `#4f46e5` 这样的色值，回车即生效

**位置一览**（点开就是「色板 + RGB 取色器 + 十六进制」三合一的面板）：

- 项目管理里每个项目的颜色
- 新建项目时的颜色
- 状态管理里每个状态的颜色、新建状态的颜色
- 右键任意任务条 →「给任务条单独指定颜色…」（留空 / 点「恢复默认」= 跟随项目色）
- 右键任意依赖线 →「给这条线单独指定颜色…」
- 左侧设置抽屉 →「画笔默认颜色」
- 右下角画笔面板里的自定义颜色

任务条的颜色和它的状态外框是**两回事**：条身用你指定的颜色，外框永远用状态颜色，
所以「单独换个条色」不会把状态信息弄丢；依赖线换色之后，那条线会立刻变成你选的颜色。

拖动取色器里那条彩虹色相条时，颜色是「**边拖边变**」的实时预览，松手（或停手一下）才真正落定；
一整趟拖动只算**一步**操作，所以按一次 <kbd>Ctrl+Z</kbd> 就能把这次改色整体还原。

> 「彩虹小圆点」本身也重新画过：它的**色环用的就是上面那一排预设色**
> （不是随便糊一条彩虹），中心是**当前颜色**的实心点，外圈留了描边，
> 浅色 / 深色主题下都看得清它现在是什么状态。

## 任务条上的文字颜色

把一条任务条换成**亮色**（比如浅黄、浅绿）之后，上面原来的白字就糊成一片了。
这一版任务条的文字会**自动挑一个看得清的颜色**：

- 条身是**亮色** → 文字自动变**深墨色**（`#16202c`）
- 条身是**暗色 / 中等饱和度**（靛蓝、湖蓝、酒红…） → 文字保持**白色**

判断用的是 W3C 那套**相对亮度 / 对比度**公式，还多加了一条「不能太花哨」的保险：
只有当深色字的对比度**明显**比白字好（好出一大截）时才翻成深字。
否则一排颜色深浅不一的条子就会「**忽黑忽白**」，反而更乱。

想**固定**某条任务的文字颜色时，双击任务打开编辑窗口 →「**条上文字颜色**」那一行：

| 选项 | 效果 |
| --- | --- |
| **自动** | 默认。按条身颜色明暗自动挑深字 / 白字 |
| 白色点 | 这条永远用白字 |
| 深墨点 | 这条永远用深墨色 |
| 色环（最后一个） | 点开完整 RGB 取色器，任何颜色都行 |

「自动」不受影响的那部分条子、以及你没动过的任务，全都继续走自动逻辑。

## 任务条外框的粗细

设置抽屉 →「甘特图」分组里有一个「**任务条外框粗细**」滑条，范围 0 ~ 6 px：

| 值 | 效果 |
| --- | --- |
| `0` | 完全不要外框，只剩纯色条（想彻底清爽时用） |
| `2` | 默认值，状态色描边清晰可辨 |

汇总条（父任务）三处同时起效，并且会跟着 UI 状态一起记住。

## 拖排序的两条规矩（甘特大纲 / 列表 / 拖任务条都适用）

**1）只在同级之间换位，绝不改变任务的层级**

大纲和列表都是缩进着排的，最后一行往往是别人的子任务。如果直接按「落点那一行」去插，
拖到列表底部就会把任务整棵子树悄悄塞进某个父任务下面 —— 那会连带影响汇总进度、依赖和统计口径。
所以这里只在「同一个父任务下的兄弟」里就近取落点：拖到最下面 = 排到同级最后一条的后面；
同级没有别的行时给一句提示，不会静默乱动。

**2）拖之前会先把「眼下看到的顺序」冻结成手动顺序**

视图可能正按开始日 / 优先级 / 进度 / 状态排序，而手动顺序是另一份数据。
直接改手动顺序等于白改（看到的顺序不变），所以第一次拖行时会自动把当前所见顺序固化成手动顺序，
并把排序切换成「手动」—— 这样落点才是所见即所得。
拖完之后想回到按日期排序，在列表视图的排序下拉里切回去即可。

| 操作 | 效果 |
| --- | --- |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | 批量删除（会一并删掉它们的子任务，确认框里会写明） |
| 右键 | 弹出批量菜单（删除选中项 / 取消选择） |
| <kbd>Esc</kbd> | 取消选择 |
| <kbd>Ctrl+A</kbd> | 全选当前视图里的任务 |

单击空白处也能取消选择；单击任务条 / 任务卡 = 高亮选中，**双击才是打开编辑弹窗**。

## 选中依赖线之后能做什么

## 背景涂色 / 画笔

### 怎么开启（一步就够）

甘特图右下角有一个圆形画笔按钮 🖌，**点它一下就直接进入涂色模式**，再点一下退出。开启后：

- 圆按钮会铺满当前笔色（用橡皮时变成红色并换成 🧽 图标），外圈有呼吸光环
- 画布左下角浮出一条状态条：「画笔已开启 · 按住左键涂色　Esc 退出」（点这条状态条也能直接退出）
- 鼠标移到轨道上会变成十字光标，提示「现在点下去是涂色，不是拖任务」

### 选颜色 / 换橡皮

鼠标**一靠近**那个圆按钮，调色面板就会自动展开（不用先点开），移开鼠标几秒后自己收起来。面板里：

| 元素 | 作用 |
| --- | --- |
| 涂色 / 橡皮 | 点哪个就切到哪个（同时自动确保画笔是开着的） |
| 12 个色块 | 点一下就换色，并自动切回「涂色」 |
| 当前颜色 | 面板里会实时显示正在用的颜色 / 是否在用橡皮 |
| 清空全部涂色 | 一键清掉所有涂色（会先确认，且可以 <kbd>Ctrl+Z</kbd> 撤销） |
| 退出画笔 | 关掉画笔（等同于点圆按钮或按 <kbd>Esc</kbd>） |

### 怎么涂

画笔开启后，在时间表上用左键按住拖动即可，**一笔涂过多少格都算一次操作**，
按一次 <kbd>Ctrl+Z</kbd> 就能整笔撤销。

### 色带的样子

同一行里连续涂过的格子会拼成一条**连续的色带**，只有整条的两端是圆角，中间是平的，
不会一格一个圆角像一串药丸；断开的部分各自成一条。

### 其他

涂色按「某一天 × 某一行任务」记，所以既能横着涂一段日期，也能竖着涂一列。
色块画在任务条**下面**，不会挡住任务；鼠标悬停时行高亮是半透明的，涂过的颜色仍然看得见
（深色主题下会自动提高不透明度，免得浅色被压成灰）。

涂色随数据一起保存、导出、导入，刷新后仍在；画笔本身是「本次打开」的状态，
刷新后会回到关闭（免得一进来就误涂）。<kbd>Esc</kbd> 可以关掉画笔；
开着画笔时，轨道上的左键拖动都是涂色，不会误拖任务。

## 拖圆点新建任务：在鼠标位置弹模板菜单

拖任务条两端的圆点松手时，就在**松手的那个位置**弹出一个选模板的小菜单：

```
通用任务 3 天 / 功能开发 5 天 / Bug 修复 1 天 / 方案评审 1 天 / 例会 1 天 …
─────────────
不用模板，直接编辑这条任务…
管理模板…                        （点这条会打开左侧设置抽屉的模板区）
```

点某个模板 → 立刻按它的工期 / 优先级 / 状态 / 工时建好任务（如果新任务还是
「新任务（后续）」这种默认名，会顺手改成模板里设定的任务名），并自动接好依赖；
之后要不要弹编辑窗口，看下面那个「新建后弹窗」开关。

这个菜单的位置**跟着鼠标走**，所以连着建几条任务时不用来回找菜单。

## 「拖圆点后弹不弹模板菜单」和「新建后弹不弹编辑窗口」两个开关在哪

都在左侧设置抽屉的「**新建任务**」段里（左上角「⚙ 设置」进去）：

| 开关 | 默认 | 说明 |
| --- | --- | --- |
| 拖圆点后弹出模板菜单 | 开 | 关掉之后，拖圆点会直接按「默认模板」把任务建好，不再弹菜单打断你 |
| 新建后弹出编辑窗口 | 开 | 关掉之后，新任务建好就完事，不会弹窗（仍可 <kbd>Ctrl+Z</kbd> 撤销） |

工具栏上也有一个「新建后弹窗」开关，位置一样、状态同步。

另外，新建任务弹窗顶部还留着一条「以后拖动圆点新建任务时，也自动弹出这个窗口」，
在弹窗里顺手取消勾选也行。

## 任务模板

**入口**：左上角「⚙ 设置」→ 抽屉里的「任务模板」段（抽屉可以点 📌 钉住，改起来更顺手）。

- 每个模板包含：模板名、任务名、工期（天）、优先级、状态、预估工时、备注
- 点最左边的圆圈把某个模板设为「**默认模板**」
- 可以自由新增 / 修改 / 删除模板，也能一键恢复内置的 5 个模板
- 模板会随 JSON 备份一起导出 / 导入

另外，在「新建任务」弹窗顶部有一个「**套用模板**」下拉框，选一个就会把上面那些字段
自动填进表单，之后再手工微调即可。

## 撤销

任何改动（新建 / 删除 / 改状态 / 改日期 / 建删依赖 / 改字段）都能按 <kbd>Ctrl+Z</kbd> 逐步撤销，
最多可回退 **150 步**；撤销后视图滚动位置同样保持不变。

编辑弹窗打开时 <kbd>Ctrl+Z</kbd> 不会误触，弹窗里输入框内的 <kbd>Ctrl+Z</kbd> 仍是浏览器自带的文本撤销。

## 自定义任务状态

**入口**：右上角「⋯」菜单 →「自定义任务状态…」；也可在各视图右上角的「管理状态」按钮，
或看板最右侧的「＋ 新建状态 / 列」，或任务编辑弹窗里的「管理 / 新建状态…」。

三类内置**核心状态**：待办 / 进行中 / 已完成（可改名、换色、排序，**不可删除**）。

新建自定义状态时可指定两件事：

1. **类型**：未开始 / 进行中 / 已完成
   —— 决定统计口径。选「已完成」的任务在切过去的瞬间记录完成时间，
   进度自动置 100，并计入完成率与完成时间统计
2. **作用范围**：
   - `所有任务`（通用状态）—— 任何项目的看板 / 列表 / 甘特图上都能选到
   - `指定项目`（专属状态）—— 只在选中的项目里出现，适合某个项目特有的流程节点

看板中带项目名的列就是专属状态列；仪表盘「状态构成」里带「专属」标记的也是。

删除自定义状态时，仍在使用它的任务会自动回退到「待办」，**不会丢数据**。

> **在这个弹窗里连续加 / 删 / 改状态，弹窗不会跳回顶部**
> 每加一个状态，列表里那一行会**闪一下高亮**告诉你「就是这一条」，
> 而弹窗的滚动位置、以及你在下面「新建状态」表单里刚敲进去的名字和刚挑的颜色，**都原样留着**
> —— 可以直接接着建下一个。

> **★ 状态不会在项目之间乱串**
> 新建状态时，如果你正停在某个项目标签上，会默认选好「指定项目」并把这个项目勾上 ——
> 也就是说在 A 项目里建的状态，B 项目里是干干净净的，不会凭空多出一堆列。
>
> 如果之前误建了一批「所有任务」的通用状态，想收拾一下：进状态管理弹窗，
> 点「**把通用状态收归当前项目**」—— 它会把所有「没有别的项目在用」的通用状态
> 改成当前项目的专属状态（别的项目还在用的会跳过，不会把人家的看板弄坏）。
>
> 「全部项目」视图里的看板列也收紧了：只显示核心状态和确实有任务在用的状态。

## 甘特图上拖圆点建依赖 / 新建任务

把鼠标移到某条任务附近（也可以停在它右外侧的文字标签上），任务条左右两端各会出现一个圆点，
圆点颜色与任务条一致。圆点平时是隐藏的，只在鼠标靠近时出现，
所以不会挡住条身的拖动与两端的「改工期」手柄。

| 圆点 | 拖到任务上 | 拖到空白处 |
| --- | --- | --- |
| **左圆点** = 接「前置」 | 本任务排在那条任务之后 | 按落点日期新建一个「前置任务」 |
| **右圆点** = 接「后续」 | 那条任务排在本任务之后 | 按落点日期新建一个「后续任务」 |

拖拽过程中会有一条虚线跟着鼠标，落在哪个任务上那个任务就会被高亮描边；
落在空白处则显示一条竖线和一个提示气泡，写明新任务将出现的日期区间与套用的模板。

> **★ 新任务就长在鼠标松手的位置**
> - **日期** = 落点那一天（右圆点从这天开始，左圆点到这天结束），不再被「贴边顺延」挪走
> - **行** = 落点那一行（落在上半格插到该行之前、下半格插到该行之后），其他任务会立刻让位；
>   落在阶段行下半格则直接成为该阶段的子任务
> - 自动接好依赖、继承源任务的项目，再套用「默认模板」的工期 / 优先级 / 状态 / 工时
>
> 松手时就在**鼠标位置**弹出模板菜单（「拖圆点后弹出模板菜单」开关打开时），
> 点一个模板立刻套上；关掉这个开关就直接用「默认模板」建好，不弹菜单。
> 之后是否弹出编辑框，取决于「新建后弹窗」开关（默认弹，两个开关都在左侧设置抽屉的
> 「新建任务」段里，也可以在新建任务弹窗里直接关掉）。

几种情况会被**拒绝**并给出提示：连到自己、两个任务之间已有依赖、会形成循环依赖、
父任务与自己的子任务之间连接、跨项目连接。按住 <kbd>Esc</kbd> 或把鼠标松开在表格之外即取消。

> **★ 行下面永远留着一块「空白区」**（表格底部虚线隔开的那片）
> 任务只有几行的时候，下面也照样铺满一大片空地，所以任何时候都有地方松手新建任务，
> 不会出现「格子跟着任务数量长、没地方放」的情况。
>
> - 把圆点拖到这片空白里松手 = 按落点日期新建一条任务，追加到列表最后（不挂到任何阶段下）
> - 在这片空白里**双击** = 按双击的那天新建一条任务，同样追加到最后
> - **右键**这片空白 = 快捷菜单（在这天新建 / 新建并打开编辑 / 展开全部任务）
> - 把圆点拖到某个项目的「项目分组行」上松手 = 追加到那个项目的末尾
>   （落在别的项目上就归到那个项目去，跨项目不会自动连依赖；那一行会先亮起来提示你）

## 完成时间统计怎么算

- **用时** = 任务开始日期 → 状态变为「已完成」类型的那一天（就是列表里那个被锁定的用时）
- **相对截止** = 完成日期与截止日期的差，正数为提前完成，负数为超期

把任务从「已完成」改回其他状态会清空该记录；
也可以在状态菜单里选「清除完成时间记录」单独清掉时间。

## 测试数据

右上角「⋯」菜单 →「载入状态测试数据」，一键生成一套专门用来试状态的样例：

- **4 个项目**：状态测试台（主场景）/ 官网改版 v2 / 个人年度计划 / 旧项目（已归档）
- **15 种状态**：3 个核心状态 + 9 个通用自定义 + 3 个项目专属
  （专属为「待客户确认」→ 官网改版 v2，「已打卡」「计划中」→ 个人年度计划）
- **41 个任务**，覆盖：
  - 每种状态至少一张卡（看板 15 列每列都有内容）
  - 3 种类型齐全：未开始 4 种 / 进行中 8 种 / 已完成 3 种
  - 完成时间样本：近 14 天陆续完成，含提前、准时、超期三种口径
  - 时间边界：逾期 3 天、今天到期、明天到期、6 天后到期、里程碑
  - 父子汇总：全部子任务完成 → 父任务自动「已完成」；部分完成 → 「进行中」
  - 已归档项目，用来验证「全部 / 已归档」作用域切换

这些状态和任务都是普通数据，可以随便改、随便删；玩坏了再重新载入一次即可。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| <kbd>N</kbd> | 新建任务 |

## 注意

- 请保留 `index.html` 的完整文件名与后缀，**直接双击打开**（不要用编辑器打开）
- 「自选保存位置」（系统另存为对话框）需要较新的 Chrome / Edge；
  如果浏览器不支持，保存会自动退回「下载到下载目录」，功能不受影响
- **附件只支持在页面里直接上传 `.md` 笔记和 `.pdf`**（这两种浏览器自己就能渲染）；
  其它格式一律走「📋 粘贴文件路径」，项目里只存那一行路径，不读文件内容
- **路径型附件单击 = 复制路径**，程序不会去「打开」任何东西 ——
  网页没有这个能力，硬来的结果就是弹一个看不懂的报错框
  （原因见上面「为什么网页不能直接打开文件？」那节）
- 首次打开会自动带一套「示例数据」，方便先看看长什么样
- 想换成专门试状态的那套，就用右上角「⋯」菜单 →「载入状态测试数据」
- 想彻底清空、从零开始，用「**清空全部数据**」（操作前建议先导出一份备份）
